# 交接记录

重要阶段或跨会话工作使用独立 Markdown 文件记录。文件名建议采用 `YYYY-MM-DD-主题-序号.md`，内容至少包含当时状态、已完成、实际验证、失败或中断、未提交改动、已知限制和后续动作。

交接只追加，不覆盖。生成文件后，将路径、SHA-256 和创建时间追加到[追溯源](../../traceability.json)的 `handoffs`，让 `state.latest_handoff` 指向最后一条，再同步[当前状态](../current.md)。更正、迁移或事实变化时增加新交接，不能回写旧文件。

交接描述当时事实，不替代当前状态；历史中的旧路径可以保留，由新交接说明变化。哈希检查发现记录与登记值不一致，但不提供外部防篡改存储。
