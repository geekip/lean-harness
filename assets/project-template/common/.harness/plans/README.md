# 已冻结的实施与验收方案

本目录只保存已确认冻结的实施与验收方案，不存占位计划、未确认草稿或执行日志。当前尚无冻结方案。

方案至少说明稳定 ID、关联已批准设计、实施范围与排除项、步骤和依赖、交付物、验收条件与证据要求、确认人及确认依据。冻结后登记到[追溯源](../traceability.json)，由任务引用；方案存在不证明工作已完成。

未确认的技术候选保留在[设计讨论](../design/README.md)，用户意见留在[用户资料](../document/README.md)。方案被替代后，有追溯价值的原文按[历史归档规则](../history/README.md)保存；不能静默改写旧方案来适配已经发生的结果。
